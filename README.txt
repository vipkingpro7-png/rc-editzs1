RC_EDITZS1 PWA starter
======================

Included:
- index.html: responsive black/red anime channel website
- manifest.webmanifest: installable web app metadata
- sw.js: basic offline caching
- icon.svg: starter app icon

IMPORTANT:
This ZIP is a starter website, not an APK. It has not been published or packaged.
Before publishing:
1. Replace placeholder wallpaper cards with artwork you own or have permission to use.
2. Add your real contact email in index.html (search for configuredEmail).
3. Upload all files to an HTTPS static host.
4. Test the live website on Android.
5. Enter the live HTTPS URL at https://www.pwabuilder.com/ to generate an Android package.
6. Keep signing keys safe. For Google Play, follow current Play Console requirements and review.

The contact form is deliberately not connected to a server. It will show a demo notice until you configure an email address.
